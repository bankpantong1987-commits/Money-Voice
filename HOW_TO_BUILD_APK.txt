วิธีสร้างไฟล์ APK - Money Voice (ทำในคอม 10 นาที)

วิธีที่ 1: ใช้ GitHub Actions (แนะนำ ไม่ต้องลง Android Studio)
1. สร้างบัญชี GitHub ฟรีที่ github.com
2. สร้าง Repository ใหม่ชื่อ money-voice
3. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (ลากโฟลเดอร์ money_voice_flutter ขึ้นไปเลย)
4. กดแท็บ Actions > กด Run workflow > รอ 3-5 นาที
5. พอเสร็จ กดโหลดไฟล์ money-voice-apk > จะได้ไฟล์ app-release.apk
6. ส่งไฟล์ APK นี้เข้า LINE / Google Drive ของตัวเอง แล้วเปิดในมือถือกดติดตั้ง

วิธีที่ 2: สร้างในคอมตัวเอง (ถ้ามี Android Studio)
1. ติดตั้ง Flutter + Android Studio
2. เปิดโฟลเดอร์ money_voice_flutter ใน VS Code
3. รันคำสั่ง:
   flutter pub get
   flutter build apk --release
4. ไฟล์จะอยู่ที่ build/app/outputs/flutter-apk/app-release.apk

วิธีติดตั้ง APK ในมือถือ
1. เปิดไฟล์ APK ในมือถือ
2. ถ้าขึ้นเตือน ให้กด อนุญาตให้ติดตั้งจากแหล่งที่ไม่รู้จัก
3. กดติดตั้ง
4. เปิดแอป แล้วทำตามหน้าขอสิทธิ์:
   - อ่านการแจ้งเตือน > เปิด
   - ไม่จำกัดแบตเตอรี่ > เปิด
   - การแจ้งเตือน > อนุญาต
5. สมัคร Pro ก่อนทดสอบพับแอป / ล็อกจอ เพราะฟรีทำงานแค่ตอนเปิดแอปค้างไว้

วิธีทดสอบหลังติดตั้ง APK
- เปิดแอปค้างไว้ > ให้เพื่อนโอน 1 บาท > ต้องได้ยิน เงินเข้า 1 บาท
- พับแอป (Pro) > ให้เพื่อนโอน 1 บาท > ต้องได้ยินทั้งที่พับอยู่
- ล็อกจอ (Pro) > ให้เพื่อนโอน 1 บาท > ต้องได้ยินทั้งที่ล็อกอยู่
- ปิด-เปิดเครื่อง (Pro) > ไม่ต้องเปิดแอป > ให้เพื่อนโอน 1 บาท > ต้องได้ยิน
